
# AI-Based Manufacturing Quality Inspection Planner

## Project Overview
An AI-based academic prototype for manufacturing quality inspection using Python, Machine Learning, Rule-Based Decision Making, and BFS.

## Technologies Used
- Python
- Streamlit
- Pandas
- NumPy
- Scikit-learn
- Isolation Forest
- Breadth-First Search (BFS)

## Features
- Product measurement input
- Anomaly detection
- PASS, REINSPECT, HOLD, and REJECT classification
- Inspection route planning using BFS
- Interactive dashboard
- Dataset analysis and charts

## Installation

Install the required packages:

```bash
pip install -r requirements.txt
```

## Run the Application

```bash
python -m streamlit run app.py
```

Open http://localhost:8501 in your browser.

## Dataset
The project uses manufacturing_data.csv as a sample dataset.

## Disclaimer
This is an academic prototype. Its dataset and decision thresholds are illustrative and are not certified industrial standards.
